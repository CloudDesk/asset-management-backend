## 💡 Quick Integration Example

### In Login Route (`/v1/auth/signin`)

```typescript
import { authSessionService } from '../services/authsession.service.js';

// After successful authentication
const session = await authSessionService.createSession({
  userId: user.id,
  userType: 'inventory',
  refreshToken: generatedRefreshToken,
  expiresInDays: 7,
  ipAddress: request.ip,
  userAgent: request.headers['user-agent'],
});

// Optionally limit sessions
await authSessionService.enforceSessionLimit(user.id, 'inventory', 5);
```

### In Refresh Route (`/v1/auth/refresh`)

```typescript
// Rotate token (delete old, create new)
const newSession = await authSessionService.rotateRefreshToken(
  oldRefreshToken,
  newRefreshToken,
  'inventory',
  7
);

if (!newSession) {
  return reply.code(401).send({ message: 'Invalid refresh token' });
}
```

### In Logout Route (`/v1/auth/signout`)

```typescript
// Logout from all devices
await authSessionService.revokeAllUserSessions(
  request.user.id,
  'inventory'
);
```

## ❓ FAQ

**Q: Do I need pg_cron?**  
A: No! We use node-cron which runs in your Node.js app.

**Q: How do I run cleanup manually?**  
A: Use `runCleanupNow()` from `sessionCleanup.ts`

**Q: What about UUID generation?**  
A: Prisma uses `gen_random_uuid()` (PostgreSQL 13+) automatically

**Q: Can I change the cleanup schedule?**  
A: Yes! Edit the cron expression in `sessionCleanup.ts`
